Agent PR Review Kit

Typing got cheaper. Review bandwidth did not. Teams merge dozens of PRs credited to Claude Code or Codex and end up rubber-stamping. This kit is for leads and small teams who want a human review process that still says no.

Some teams report most merged PRs co-authored by Claude. The free tip is "read the diff." This kit packages a risk rubric, a timed checklist, and a documented "no" so you do not invent the process under load.

  • Risk rubric by change type: how deep to look when the agent touched auth, schema, deps, or UI-only files.
  • 12-minute review checklist: a fixed path so review time stays bounded when PR volume spikes.
  • Minimum tests before merge: the smallest test bar you require before approving an agent PR.
  • Documented "no" template: a short write-up when you roll back or reject, so the team learns once.
  • Approval rule: who may approve PRs with Co-Authored-By Claude or Codex (and when that person cannot).

We are measuring paid interest before building it. Join only if you want the packaged process, not another AI reviewer bot.
